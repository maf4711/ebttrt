# ebttrt-doctor

```bash
ebttrt doctor
ebttrt
ebttrt next
```

If doctor fails, run `ebttrt activate` from the ebttrt repo (safe, local, idempotent). On a new Mac that is the only command after the tree is copied. Then start a new Grok session or press `r` in the Plugins tab.

Do not reinstall on top of a second copy. One link: `~/.grok/plugins/ebttrt` → the repo.
