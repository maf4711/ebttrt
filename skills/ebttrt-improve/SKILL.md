# ebttrt-improve

The always-on rule stays short. New knowledge becomes a **skill**, not another bullet in `ebttrt-loop.md`.

1. Run `ebttrt improve` — it lists only instincts with confidence > 0.5 and two receipts.
2. Promote only something that happened **twice** and still holds.
3. Write a focused skill (name + description + steps). Prefer project scope (`.grok/skills/`) for repo-specific wins.
4. Do not copy ECC catalogs. Do not duplicate Superpowers or Ruflo.

First remember stays at 0.5. Confidence below or equal 0.5 stays an instinct.
