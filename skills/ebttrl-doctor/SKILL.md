# ebttrl-doctor

```bash
ebttrl doctor
ebttrl
ebttrl next
```

If doctor fails, run `ebttrl activate` from the ebttrl repo (safe, local, idempotent). On a new Mac that is the only command after the tree is copied. Then start a new Grok session or press `r` in the Plugins tab.

Do not reinstall on top of a second copy. One link: `~/.grok/plugins/ebttrl` → the repo.
